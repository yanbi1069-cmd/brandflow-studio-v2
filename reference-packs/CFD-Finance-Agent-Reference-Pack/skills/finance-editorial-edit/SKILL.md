# Finance editorial video edit

Use the training pack at `workspace/share/nhi-finance-editorial-training-pack/` as the approved reference. Read its `README_FOR_AGENT.md` and `docs/QA_CHECKLIST.md` before editing. Read `docs/AUDIO_PRESET.md` only when mixing audio.

Start from the supplied footage and its spoken audio. Map each meaningful narration beat to one visual action. Technical claims need a full-screen chart, diagram or motion graphic that proves the explanation; real-world B-roll is supplemental context only.

Keep hook and final CTA as full-screen talking-head unless the source demands otherwise. Keep every technical proof visible long enough to understand. Do not use a fixed cut interval. If an explanation continues after a B-roll ends, return cleanly to the talking head rather than holding a stale image.

Subtitles must follow the actual speech, break at natural punctuation or meaningful clauses, stay within two lines and remain inside the safe area. Avoid captions that overlap chart labels.

Before delivery, watch the full render and inspect all scene boundaries for flash frames, accidental one-frame overlays, cut-off text, unfinished visual proof, subtitle mismatch and audio imbalance.
