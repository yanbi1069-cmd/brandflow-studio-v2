# CFD Finance Agent — Reference Pack

Thư mục này gom toàn bộ tài liệu cần thiết để một phiên Codex khác tham khảo và phát triển Agent theo hướng mới.

## Nội dung

- `localhost-app/` — mã nguồn ứng dụng localhost và tài liệu chạy.
- `skills/cfd-finance-personal-brand-agent/` — skill điều phối toàn pipeline.
- `skills/finance-editorial-edit/` — skill dựng video Finance/Forex.
- `nhi-finance-editorial-training-pack/` — training pack phong cách editorial.

## Prompt bắt đầu cho phiên khác

> Đọc toàn bộ `README.md`, `skills/cfd-finance-personal-brand-agent/SKILL.md` và các reference được skill chỉ định. Xem `localhost-app/` là baseline hiện tại. Trước khi chỉnh sửa, hãy phân tích kiến trúc và đề xuất hướng phát triển riêng; giữ nguyên checkpoint duyệt video, duyệt kịch bản, xác nhận HeyGen và xác nhận xuất bản.

## Bảo mật

File `.env` không được đưa vào reference pack. Mỗi phiên hoặc máy phải tự cấu hình API key cục bộ từ `.env.example`.
