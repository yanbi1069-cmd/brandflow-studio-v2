# CFD Finance Local Agent — Operating Rules

1. Preserve explicit approval gates: selected competitor video, approved script, external-cost render, approved final, publishing.
2. Never copy a competitor script, watermark, proprietary chart, or personal likeness. Use competitor content only to find demand and content gaps.
3. Present financial mechanisms conditionally. Never invent market data, guarantee profit, or give direct buy/sell/all-in instructions.
4. Use the approved script/voice as the timeline source of truth. Technical claims require readable visual proof.
5. Run the local `finance-editorial-edit` skill for editing and use `workspace/share/nhi-finance-editorial-training-pack` as the default editorial reference.
6. Keep old versions. Feedback creates a new version; it does not overwrite an approved render.
7. Publishing defaults to Skip. Only publish after a current, explicit confirmation of platform, profile, file, and schedule.
