# Personal Brand Video Agent — Operating Rules

1. Preserve explicit approval gates: selected competitor video, approved script, external-cost render, approved final, publishing.
2. Never copy a competitor script, watermark, proprietary chart, or personal likeness. Use competitor content only to find demand and content gaps.
3. Apply the selected domain pack. Never invent facts or results; Finance additionally forbids profit guarantees and direct buy/sell/all-in instructions.
4. Use the approved script/voice as the timeline source of truth. Claims require readable proof appropriate to the selected domain.
5. Run the project `multi-style-video-editor` skill for editing. Finance keeps `nhi-finance-editorial-training-pack` as its baseline reference; other niches use the selected style and domain proof types.
6. Keep old versions. Feedback creates a new version; it does not overwrite an approved render.
7. Publishing defaults to Skip. Only publish after a current, explicit confirmation of platform, profile, file, and schedule.
