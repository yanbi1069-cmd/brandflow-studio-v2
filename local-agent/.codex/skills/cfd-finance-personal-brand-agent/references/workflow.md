# Workflow

## Entry routes

- Full: research → select → scripts → source route → edit → QA → distribution.
- Script: user script or three generated scripts → source route → edit → QA → distribution.
- Edit-only: upload source video → edit → QA → distribution.
- Publish-only: final file + metadata → optional publish.

## Approval gates

1. Research is complete only after the user approves one candidate video.
2. Script is complete only after the user approves one editable candidate or their imported script.
3. HeyGen may run only after credit confirmation. No-face does not consume HeyGen credit.
4. Final may advance only after full-watch QA and user approval.
5. Publishing requires a separate current confirmation; Skip is always valid.

## Research output

Return platform, original URL, views, likes, comments, shares when available, engagement rate, viral score, and a concise viral hypothesis. Keep zero or unavailable metrics honest.

## Script output

Create three distinct angles. Each includes the full editable text plus analysis of hook, body structure, visual proof, and CTA. Run a claim-risk check before approval.

## Source routes

- HeyGen Avatar: voice ID, one or more avatar IDs, scene rotation, vertical dimensions.
- No-face: voice source, beat-level visual plan, technical/real-world/stock mix.
- Upload: preserve the user's original file inside the project.
